# 📊 HR Analytics Dashboard – Employee Attrition Analysis

An interactive **HR Analytics Dashboard built with Power BI** to analyze employee attrition, workforce patterns, salary trends, job roles, tenure, and employee satisfaction. The project transforms raw HR data into meaningful visual insights that can support **data-driven HR decisions and employee retention strategies**.

## 🎯 Project Objective

The main objective of this project is to understand **why employees leave an organization** and identify workforce patterns that can help HR teams improve employee retention and experience.

## 🛠️ Tools & Technologies

* **Power BI** – Interactive dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations
* **Data Visualization** – Charts, KPI Cards, Matrix Tables & Slicers

## 🔍 Key Analysis

The dashboard provides insights into:

* 👥 Total Employees & Total Attrition
* 📈 Overall Attrition Rate
* 💰 Average Salary
* ⏳ Average Employee Tenure
* ⚧️ Gender-wise Attrition
* 💵 Attrition by Salary Slab
* 🎂 Attrition by Age Group
* 📅 Attrition by Tenure
* 💼 Attrition by Job Role
* 😊 Job Satisfaction Analysis
* 🏢 Department-wise Attrition
* 🎓 Education-level filtering

## 🧹 Data Preparation

Using **Power Query**, the data was prepared by:

* Validating and standardizing data types
* Cleaning inconsistent categorical values
* Removing irrelevant/null columns
* Eliminating duplicate records
* Creating an **Attrition Status** column using conditional logic

## 📐 DAX Calculation

Created an **Attrition Rate (%)** measure:

`Attrition Rate = Total Attrition Count / Total Employee Count`

The result is displayed as a percentage KPI for quick workforce monitoring.
